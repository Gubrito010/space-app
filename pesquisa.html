1. O que são Keyframes no CSS?

Os Keyframes são utilizados para criar animações no CSS.

• Para que servem?

Os Keyframes no CSS servem para criar animações em elementos da página, definindo como eles começam, se movimentam e terminam durante a animação.

• Como funcionam?

Funcionam através da regra @keyframes, onde definimos os estados da animação em porcentagens. 

@keyframes mover {
  0% {
    transform: translateX(0);
  }

  100% {
    transform: translateX(200px);
  }
}

• Onde são utilizados?

São utilizados em sites modernos para criar efeitos visuais, carregamentos, menus animados, botões interativos, banners e transições suaves.

2. O que faz a propriedade animation?

A propriedade animation controla uma animação criada com @keyframes.

  • duration: define o tempo da animação.
  • infinite: faz a animação repetir infinitamente.
  • alternate: faz a animação ir e voltar.
  • linear: mantém velocidade constante.
  • ease: começa devagar, acelera e termina devagar.
  • ease-in: começa lentamente.
  • ease-out: termina lentamente.
  • ease-in-out: começa e termina lentamente.

3. Funções

translate()

Move um elemento na horizontal ou vertical.

rotate()

Rotaciona um elemento.

scale()

Aumenta ou diminui o tamanho de um elemento.

skew()

Inclina um elemento.

4. Diferença entre transition, transform e animation

Propriedade Função
transition Cria uma mudança suave entre estados.
transform Modifica visualmente um elemento.
animation Cria animações completas usando keyframes.
